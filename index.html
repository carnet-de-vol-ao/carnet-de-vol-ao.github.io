☁️ Sauvegarde en ligne (GitHub)

Vos données sont enregistrées dans ce navigateur et dans le dépôt GitHub du site (fichier data/carnet.json, historique de toutes les versions conservé par GitHub). Ainsi rien n'est perdu, même si vous changez d'ordinateur ou videz le navigateur. Il faut une seule fois coller un jeton d'accès GitHub (il reste uniquement dans ce navigateur).

Créer un jeton ↗
Comment créer le jeton (2 min)
  1. Cliquez « Créer un jeton », donnez-lui un nom (ex. Carnet de Vol) et une expiration (jusqu'à 1 an, ou « No expiration »).
  2. Repository access → Only select repositories → choisissez le dépôt du carnet.
  3. Permissions → Repository permissions → Contents : Read and write.
  4. « Generate token », copiez-le, collez-le ci-dessus puis « Connecter ».
